# TypeScript Commands

## Important: Where to Run Commands

Run TypeScript project commands from the **project root directory**, where `tsconfig.json` is located.

Example:

```cmd
D:\projects_repos> npx tsc
```

Do not run project commands from subdirectories such as `src/` or `dist/`, because TypeScript may not find the root `tsconfig.json` and may use different default settings.

## 1. Check TypeScript Version

```cmd
npx tsc --version
```

## 2. Create TypeScript Configuration

```cmd
npx tsc --init
```

## 3. Compile TypeScript Files

```cmd
npx tsc
```

Compiles files according to `tsconfig.json`.

## 4. Compile a Specific File

```cmd
npx tsc src/index.ts
```

Compiles the specified file using command-line defaults rather than the project configuration.

## 5. Watch for Changes

```cmd
npx tsc --watch
```

Automatically recompiles when TypeScript files change.

## 6. Check Errors Without Generating JavaScript

```cmd
npx tsc --noEmit
```

Checks for TypeScript errors without generating output files.

## 7. Show Configuration

```cmd
npx tsc --showConfig
```

Displays the effective TypeScript configuration.

## 8. Compile Using a Specific Configuration

```cmd
npx tsc --project tsconfig.json
```

Uses the specified configuration file.

## 9. Compile Without Incremental Build Information

```cmd
npx tsc --incremental false
```

Disables incremental compilation for that run.

## 10. Remove Comments from Output

```cmd
npx tsc --removeComments
```

Removes comments from generated JavaScript.

## 11. Display Compilation Help

```cmd
npx tsc --help
```

Lists available TypeScript compiler options.

## 12. Display Detailed Help

```cmd
npx tsc --help --all
```

Shows all compiler options.

## 13. List Compiled Files

```cmd
npx tsc --listFiles
```

Displays files included in compilation.

## 14. Show Files Being Compiled

```cmd
npx tsc --listFilesOnly
```

Lists included files without compiling them.

## 15. Explain Why Files Are Included

```cmd
npx tsc --explainFiles
```

Explains why each file is part of the compilation.

## 16. Check TypeScript Performance

```cmd
npx tsc --diagnostics
```

Displays compilation performance statistics.

## 17. Generate Detailed Performance Information

```cmd
npx tsc --extendedDiagnostics
```

Displays more detailed compiler performance statistics.

## 18. Force Rebuild

```cmd
npx tsc --build --force
```

Forces a rebuild of projects in build mode.

## 19. Clean Build Output

```cmd
npx tsc --build --clean
```

Removes outputs generated by project build mode.

## 20. Compile with Strict Type Checking

```cmd
npx tsc --strict
```

Enables strict type-checking options for that compilation.

## 21. Set Output Directory

```cmd
npx tsc --outDir dist
```

Places generated JavaScript files in `dist/`.

## 22. Set Root Source Directory

```cmd
npx tsc --rootDir src
```

Sets `src` as the root directory for input files.

## 23. Generate Source Maps

```cmd
npx tsc --sourceMap
```

Generates `.js.map` files to help debug TypeScript using the original source.

## 24. Generate Declaration Files

```cmd
npx tsc --declaration
```

Generates `.d.ts` type declaration files.

## Notes

- `npx tsc` compiles using `tsconfig.json`.
- `--noEmit` checks for errors without generating JavaScript.
- `--watch` recompiles when files change.
- `--build` is mainly used for projects with TypeScript project references.
- `--outDir dist` sets the output directory.
- Options passed through the command line can override settings in `tsconfig.json`. Some options are intended for build mode and have specific requirements.

**Important:** Run project compilation commands from the project root directory containing `tsconfig.json`.
